Автономные виртуальные портфели

Загрузка состояния бота…

Работают в GitHub Actions без включённого компьютера. SMA20/60 по 8 акциям; целевая покупка 15% капитала, до 5 позиций; комиссия модели 0,05%, проскальзывание 0,1%. Это исследовательские настройки, не тариф БКС. Нет плеча и коротких продаж. При просадке 15% новые заявки останавливаются, открытые позиции сохраняются. Реальная торговля не подключена.

Первый запуск только создаёт сигналы. Существующие ручные сделки ниже не переносятся в автономные портфели. Обновление страницы не исполняет заявки. Пауза и возобновление: запустить workflow вручную с командой pause или resume.

Сделки выполняются только вручную по последней загруженной цене MOEX с учётом размера лота. Этот ручной режим независим от автономных портфелей выше.
