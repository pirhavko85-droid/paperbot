# PaperBot v0.7.14

GitHub Pages: https://pirhavko85-droid.github.io/paperbot/

Виртуальные портфели 50 000, 100 000 и 500 000 рублей сохраняются только в браузере. Реальная торговля не подключена.

## Данные и управление

При открытии Центр управления читает `data/latest.json`. Кнопка «Обновить всё» очищает общий кэш и запрашивает MOEX ISS заново. Повторный запуск блокируется, ошибки источников и история по акциям отображаются отдельно. Снимок даёт только справочные цены: для виртуальных сделок требуется успешное ручное обновление котировок. Вкладки используют один слой данных и сохраняют результаты при переключении.

Исследование: SMA20/SMA60, исполнение на следующем закрытии, комиссия 0,05%. Отдельные команды рассчитывают кризисные просадки и рейтинг. Окна: 2008–2009, пандемия 2020, февраль–апрель 2022, сентябрь–ноябрь 2022, высокая ставка июль–декабрь 2024. TQBR ограничивает доступность старой истории; отсутствие данных явно отмечается. Дивиденды и корпоративные действия не включены в доходность. Дивидендный источник не подключён.

## Обновление без компьютера

`.github/workflows/update-data.yml` запускается при push, вручную и по рабочим дням в 16:30 UTC (19:30 МСК). GitHub может задерживать расписание. Используется Node 24, MOEX ISS, встроенный `GITHUB_TOKEN`; пользовательские секреты и FirstVDS не нужны. Сборщик сохраняет историю с 2008 года для исследовательской выборки и IMOEX, котировки и список TQBR. При покрытии менее 80% или отсутствии IMOEX сборка завершается ошибкой, предыдущая публикация остаётся доступной. Ошибки отдельных бумаг записываются в снимок. Для бумаг вне снимка кризисный модуль обращается к MOEX непосредственно.

Pages использует существующий источник **main / root**. Workflow сохраняет снимок коммитом, затем явно запрашивает сборку Pages через API и проверяет её завершение. Не добавляйте секреты в исходники или снимок.

Проверки: `node --test tests/*.test.cjs`. Сбор вручную: `node scripts/collect.cjs`. Просмотр локально — любой статический HTTP-сервер из корня репозитория.

FirstVDS 168.113.176.205 и обращение №15025534 не используются этой архитектурой; состояние SSH и ответ поддержки не подтверждены.
