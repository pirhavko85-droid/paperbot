# PaperBot v0.8.2

Исследовательская виртуальная торговля: https://pirhavko85-droid.github.io/paperbot/

## Мобильный интерфейс

Главная страница — «Портфель». Тема постоянно тёмная, независимо от темы устройства; CSS не требует поддержки light-dark(). Показатели портфеля расположены в трёх компактных строках по два показателя, а на главной показана вся исследовательская подборка. Восемь бумаг — фиксированная текущая выборка для наблюдения, а не количество позиций и не рейтинг лучших акций.

Основной сайт адаптирован для телефона: компактная шапка с версией, переключатель трёх портфелей, логотипы акций, однострочный список, дневник выбранного портфеля и нижняя навигация. Центр управления и раздельное время источников в МСК находятся в «Ещё». Исследование и кризисные рейтинги доступны там же: на узком экране строки таблиц превращаются в карточки, высота встроенного модуля следует содержимому, отдельного внутреннего скролла нет.

Ручной интерфейс сохранён в manual.html; прежний ключ localStorage и сделки не изменены. Мобильная оболочка не исполняет торговые заявки. Правила и серверное состояние автономного движка сохранены. Логотипы компаний загружаются из закреплённой версии открытого набора funcid/take-moex-logos через jsDelivr; при недоступности изображения остаётся текстовый значок. Временный значок PaperBot находится в assets/paperbot.svg.

## Что работает

Центр управления загружает котировки, российские акции, дивиденды и историю. Автономные виртуальные портфели 50 000, 100 000 и 500 000 ₽ работают в GitHub Actions; их состояние и журнал находятся в data/paper-state.json. Отдельные ручные портфели остаются в браузере и не смешиваются с автономными. Исторический SMA20/60 и удержание включают модель дивидендов. Кризисные рейтинги остаются ценовыми. IMOEX — ценовой ориентир, не индекс полной доходности.

## Дивиденды

MOEX ISS /securities/SBER/dividends.json при проверке возвращает описание бумаги вместо выплат; этот ответ не принимается за дивиденды. scripts/dividends.cjs читает таблицу «Выплаченные дивиденды» Smart-Lab, исключает строки dividend_canceled и связывает классы акций только по точному тикеру строки. Пустая или недоступная история не доказывает отсутствие выплат. История не гарантированно полна: старые классы акций, переименования и корпоративные действия требуют сверки.

Контрольные сверки: SBER — реестр 18.07.2025, 34,84 ₽, https://www.e-disclosure.ru/portal/event.aspx?EventId=7TGhw7-A9qkK5ErPvhXMizQ-B-B; MOEX — выплаты 2025 года 26,11 ₽, https://www.moex.com/a2656. Они не превращают остальные строки в аудированную историю. Источник и время загрузки сохраняются в data/dividends.json.

Фактической даты поступления на брокерский счёт в источнике нет. Модель фиксирует право по позиции на закрытии последнего дня покупки, признаёт дивиденд к получению после этого дня и делает расчётное зачисление через 30 календарных дней после реестра. При противоречивой или неизвестной дате покупки выплата показывается в истории, но не начисляется. Продажа после даты права не отменяет дивиденд. До зачисления его нельзя потратить. Модель — до налогов, не расчёт НДФЛ. Удержание в историческом тесте не реинвестирует дивиденды автоматически. Отменённые выплаты исключены.

## Автономная виртуальная торговля

Настройки: paper-config.json. Будущий брокер БКС подтверждён пользователем. Брокерского соединения, ключей и реальных заявок нет. Движок отклоняет любой режим кроме paper-only.

Пилот: SBER, LKOH, TATN, ROSN, GAZP, NVTK, MOEX, MTSS. Это фиксированная исследовательская выборка, не рекомендация. SMA20/SMA60 строится по завершённым сессиям. Первый запуск создаёт сигналы, без исполнения исторических сделок. Сигнал исполняется по закрытию следующей завершённой сессии с модельным проскальзыванием 0,1% и комиссией 0,05%. Размер округляется вниз до биржевого лота. Целевая покупка — 15% текущего капитала, до 5 позиций; конкурирующие заявки обрабатываются по алфавиту. Это ограничение покупок, а не постоянная ребалансировка. Плеча, шортов и отрицательного денежного остатка нет. Издержки — допущения симуляции, не тариф БКС.

Повторный запуск на той же сессии не дублирует сделки. Нет торговли при отсутствии лотов/дивидендного охвата, рассогласованных датах, истории старше 7 дней или скачке цены более 35%. После пропуска нескольких сессий — пауза, без сделок задним числом. При просадке 15% от максимума заявки отменяются; открытые позиции сохраняются. Это не гарантирует ограничение потерь 15%.

Управление: GitHub → Actions → Refresh MOEX and publish Pages → Run workflow → command: pause / resume / run. Resume очищает старые заявки, начинает наблюдение с последней сессии и сбрасывает максимум контрольной просадки к текущему капиталу; пропущенные сделки не догоняются. Перед resume нужно проверить причину остановки. Причина блокировки публикуется, workflow завершается с ошибкой. Выходной без новых сессий — нормальный результат. Браузерная кнопка «Обновить всё» не исполняет автономные заявки и не управляет паузой.

## Расписание и проверки

Workflow запускается при push, вручную и ежедневно в 21:30 UTC — 00:30 МСК следующего календарного дня. GitHub может задерживать запуск. Все свечи текущей московской даты исключаются. Компьютер пользователя не нужен.

Порядок: тесты → MOEX → дивиденды → виртуальный движок → сохранение → коммит → сборка существующего Pages main / root. Используется встроенный GITHUB_TOKEN, без личных токенов. Частичные ошибки дивидендов вне пилота не блокируют его и показываются в интерфейсе. Ошибки сохранения/публикации видны в Actions.

Проверки: node --test tests/*.test.cjs. Локальная последовательность: node scripts/collect.cjs; node scripts/dividends.cjs; node scripts/paper.cjs. Для просмотра нужен статический HTTP-сервер. Не удаляйте data/paper-state.json для обычного обновления.

FirstVDS 168.113.176.205 не используется и не изменён; SSH и ответ по обращению №15025534 не подтверждены. Реальная торговля — отдельный будущий этап с брокерскими данными, учётом исполнений и дополнительными проверками. Средства будут находиться у брокера, не на сайте PaperBot.
